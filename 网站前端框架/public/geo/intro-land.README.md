# Opening globe land data

`intro-land.geojson` is Natural Earth's public-domain 1:110m land dataset,
downloaded from the maintained Natural Earth vector repository:
https://github.com/nvkelso/natural-earth-vector/blob/master/geojson/ne_110m_land.geojson

The opening animation uses this local asset for decorative orthographic rendering.
The soft East Asia highlight is a branding effect, not a model output.
