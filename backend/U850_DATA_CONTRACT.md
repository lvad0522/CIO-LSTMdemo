# U850 NetCDF 距平数据适配

上传入口为 `/api/chain/jobs` 的 `.zip` 文件，可包含 `.nc` 和 `.nc4`。文件可按日、月、年或多年组织，ZIP 名称不必含 U850；后端以文件内元数据验证变量和日期。完整预测仍要求所选提前期、目标年份存在可用模型权重。

## 支持范围

- 规则、一维经纬度网格，覆盖 20°S–20°N、40°E–120°E；排序后双线性插值至 41×81 的 1° 模型网格，不外推。保留目标边界外的插值支撑格点。
- 自动识别 `lat/latitude`、`lon/longitude`、`time/valid_time/date` 以及 CF `standard_name` / `axis` 属性。空间和时间维度可以换序，经纬度可倒序，经度可用 −180–180 或 0–360。
- U 风变量可以使用 `u850`、`uwnd`、`u`、`ua` 等常见名称，或标注 `eastward_wind`。多个候选不自动猜选。
- 多层数据通过 `level/lev/plev/pressure_level` 或 CF 气压元数据选择 850 hPa，支持 Pa/hPa。未提供层坐标时，需要明确的 U850/850 hPa 描述。其他附加维度仅接受单例。
- 风速支持 m/s、cm/s、km/h 及对应常见 CF 写法，自动换算至 m/s；支持 `scale_factor`、`add_offset` 和缺测标记。
- CF 时间单位支持 days/hours/minutes/seconds since 起点；支持 Gregorian / proleptic Gregorian / noleap / 365_day。ISO 日期也可读取。重复日期（包括小时数据）拒绝，不能以自动平均替代时间采样决策。
- 缺少时间 units 的历史 `*.YYYYMM02-28days.nc`，只有恰好 28 点时才允许按命名推断日期，适配报告明确记录这一兼容路径。有效时间坐标始终优先。

## 模型边界

这是数据格式适配，不是重新训练或自动构建气候基准。输入必须已是与研究目的相符的 U850 距平；变量、属性或文件名需标明 `anom/anomaly`。绝对风场、未知单位、不支持的日历、曲线网格、重复日期或重复经纬度、目标域缺测、非单例集合成员都会明确报错。

每个模型窗口仍选取 5 月 30−lead 日至 9 月 29−lead 日之间、每月 2–29 日的 112 个样本。完整逐日文件中的其他日期明确排除，不截取“前 112 点”冒充窗口。总样本数由实际年份和覆盖决定，不要求 2352。目标年缺日会在受理时报告具体日期；其他年份的缺日写入适配报告。

预处理继续采用历史日序平均、沿纬度滤波、MAT 固定标准化参数和 EOF 权重。归一化继续使用现有训练长度规则，短序列或扩展基准仍给警告。换数据来源或年份范围可能改变这些统计量，不能仅凭格式兼容宣称预测能力不变。

## 可追溯输出

任务的 `projection.adaptation` 返回文件数、源样本数、选中/排除样本数、缺日清单、目标网格，以及每个文件的变量、维度、单位换算、日期范围、日历和日期来源。页面“数据适配明细”展示同一报告；1c 的窗口数量由结果动态生成。

## 验证

`python -m pytest backend/test_u850_adapter.py -q -p no:cacheprovider` 用解析可解的空间场验证插值、时间对应、单位与气压层选择，并验证 NetCDF3/4、数据拒绝条件和链路产物。

`cd backend; python test_cioproj.py` 与服务器官方 CIO 序列逐提前期对拍。历史 pre7 官方文件是已知损坏负例，必须保持识别为不一致，不能为了通过而修改输入。
